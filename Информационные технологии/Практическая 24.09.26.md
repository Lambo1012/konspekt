
### Практическая работа №12

**Работа в Excel**

Excel нужен для работы с таблицами. В нём можно записывать текст и числа в ячейки, считать значения с помощью формул и быстро заполнять таблицу.

### 1. Как работать мышкой

- Левая кнопка мыши — выбрать ячейку.
- Зажать левую кнопку и провести мышкой — выделить несколько ячеек.
- Щёлкнуть по букве сверху — выделить весь столбец.
- Щёлкнуть по номеру слева — выделить всю строку.
- Двойной щелчок по ячейке — изменить её содержимое.
- Чтобы изменить ширину столбца, нужно навести мышку на границу между буквами столбцов и потянуть её в сторону.
- Правая кнопка мыши открывает меню с действиями: копировать, вставить, удалить и другие.
- Маленький квадратик в правом нижнем углу выделенной ячейки можно потянуть вниз или в сторону, чтобы **скопировать формулу или продолжить ряд чисел**.

### 2. Как работать клавиатурой

- **Стрелки** — переходить между ячейками.
- Enter — закончить ввод и перейти ниже.
- Tab — закончить ввод и перейти вправо.
- Backspace — удалить символы при редактировании.
- Delete — очистить содержимое выбранной ячейки.
- Ctrl + C — копировать.
- Ctrl + V — вставить.
- Ctrl + X — вырезать.
- Ctrl + Z — отменить последнее действие.
- Ctrl + S — сохранить файл.
- F2 — изменить содержимое выбранной ячейки.
### 3. Ввод данных

Сначала нажимаю на нужную ячейку мышкой или выбираю её стрелками на клавиатуре. Потом пишу текст или число и нажимаю **Enter**.
Например:

|                     |       |     |
| ------------------- | ----- | --- |
| ТоварЦенаКоличество |       |     |
| Ноутбук             | 45000 | 2   |
| Мышь                | 1200  | 5   |
| Клавиатура          | 3500  | 3   |

### 4. Формулы

Формула начинается со знака **=**.
Например, если цена находится в **B2**, а количество в **C2**, то в ячейке D2 можно написать: =B2*C2
После нажатия Enter Excel сам посчитает результат.
Чтобы не писать формулу каждый раз, можно нажать на маленький квадратик в углу ячейки и потянуть его вниз. Формула сама изменится для следующих строк.
### 5. Автозаполнение

Автозаполнение удобно, когда нужно быстро продолжить числа или скопировать формулу.
Например, пишу: 1 и 2`
Выделяю обе ячейки и тяну маленький квадратик вниз. Excel продолжит: 3 4 5 6
То же самое можно делать с формулами.
### 6. Как выделять диапазоны

Если нужно выделить несколько ячеек мышкой, зажимаю левую кнопку и веду от первой ячейки до последней.
С клавиатуры можно зажать **Shift** и использовать стрелки.
Например, выделить диапазон **A1:D5** — нажать на A1, зажать **Shift** и перейти стрелками к D5.

### 7. Как копировать формулы

Сначала выбираю ячейку с готовой формулой.
Например: =B2*C2
Нажимаю Ctrl + C, выбираю нужные ячейки и нажимаю Ctrl + V.
Если нужно скопировать формулу на соседние строки, удобнее потянуть маленький квадратик в правом нижнем углу ячейки вниз.
### 8. Сохранение работы

После выполнения работы нажимаю Ctrl + S. Если файл ещё ни разу не сохранялся, выбираю место для сохранения, пишу название файла и нажимаю Сохранить.
