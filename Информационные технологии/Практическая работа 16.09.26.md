
Практическая работа №10
Создание и редактирование таблиц. Сортировка таблиц. Вычисления в таблицах. Преобразование текста в таблицу
Цель работы: научиться создавать и редактировать таблицы в текстовом процессоре, выполнять сортировку данных, вычисления и преобразовывать текст в таблицу.

Программное обеспечение: Microsoft Word (или LibreOffice Writer).
1. Создание таблицы
Вкладка Вставка → Таблица.
Выбрать нужное число строк и столбцов (например, 5×4).
Таблица появится в документе.
Редактирование:
Изменение ширины столбцов — перетаскиванием границы или через Макет → Ширина.
Добавление строк — Макет → Вставить снизу/сверху.
Объединение ячеек — выделить → Макет → Объединить ячейки.
Выравнивание текста — Макет → Выравнивание.
2. Сортировка таблицы
Выделить таблицу (или столбец).
Макет → Сортировка.
Выбрать столбец, тип данных (текст/число), направление (по возрастанию/убыванию).
Пример: таблица «Фамилия — Оклад» сортируется по столбцу «Оклад» по убыванию.
3. Вычисления в таблицах
Поставить курсор в ячейку для результата.
Макет → Формула.
Ввести формулу, например:
=SUM(ABOVE) — сумма значений выше;
=SUM(LEFT) — сумма значений слева;
=AVERAGE(ABOVE) — среднее;
=PRODUCT(LEFT) — произведение.
Пример таблицы:
Товар	Цена	Количество	Стоимость
Ручка	50	10	=PRODUCT(LEFT) → 500
Тетрадь	80	5	=PRODUCT(LEFT) → 400
Итого			=SUM(ABOVE) → 900
4. Преобразование текста в таблицу
Набрать текст, разделяя данные табуляцией, запятой или точкой с запятой:
Фамилия,Имя,Возраст
Иванов,Иван,20
Петров,Пётр,21
Выделить текст.

Вставка → Таблица → Преобразовать в таблицу.
Указать разделитель (запятая) и нажать ОК.
Обратное преобразование: Макет → Данные → Преобразовать в текст.

### Практическая работа №11
Открытие приложения табличного процессора. Структура экрана. Меню и панели инструментов. Создание и сохранение документа. Знакомство с элементами окна
Цель работы: изучить интерфейс табличного процессора, научиться создавать и сохранять документы.

Программное обеспечение: Microsoft Excel (или LibreOffice Calc).

1. Открытие приложения
Пуск → Microsoft Excel (или ярлык на рабочем столе).
Либо открыть существующий файл: Файл → Открыть.

2. Структура экрана
Основные элементы окна:
Строка заголовка — имя файла и кнопки управления окном.
Лента (вкладки): Файл, Главная, Вставка, Формулы, Данные, Рецензирование, Вид.
Панель быстрого доступа — сохранить, отменить, повторить.
Строка формул — отображает содержимое активной ячейки.
Поле имени — адрес активной ячейки (например, A1).
Рабочая область — сетка из столбцов (A, B, C…) и строк (1, 2, 3…).
Ярлыки листов — Лист1, Лист2 и т.д.
Строка состояния — внизу окна (режим, сумма, масштаб).

3. Меню и панели инструментов
Главная — форматирование шрифта, выравнивание, границы, заливка.
Вставка — диаграммы, таблицы, рисунки.
Формулы — библиотека функций.
Данные — сортировка, фильтр.
Вид — режимы отображения.

4. Создание и сохранение документа
Файл → Создать → Новая книга.
Ввести данные в ячейки (например, A1 — «Товар», B1 — «Цена»).
Файл → Сохранить как → выбрать папку, имя файла, тип (.xlsx), нажать Сохранить.

5. Элементы окна (таблица для отчёта)
	Элемент	               Назначение
	Строка формул	   вод и редактирование данных/формул
	Поле имени	       Показывает адрес ячейки
	Рабочая область   Сетка ячеек для ввода данных
	Ярлыки листов  	   Переключение между листами
	Строка состояния 	Отображение режима и итогов
